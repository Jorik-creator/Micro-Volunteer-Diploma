На що зважати

    {% if tab == 'verification' %}
  • Відповіді звучать як від реальної людини, без шаблонних фраз.
  • Посилання веде на живу сторінку людини чи організації.
  • Сумніваєтеся — запропонуйте короткий відеодзвінок.
  • Не просіть документів: ми їх не приймаємо й не зберігаємо.
    • {% elif tab == 'requests' %}
  • Жодних прохань про гроші, передоплату чи дані карток.
  • Один запит — одна побутова справа з реальним часом і місцем.
  • Формат відповідає справі: візит додому — лише коли без нього ніяк.
  • Відхиляючи, поясніть, що саме виправити.
    • {% else %}
  • Кілька скарг на один об'єкт — сильний сигнал.
  • Розмову відкривайте лише для перевірки скарги.
  • Захід застосовується одразу й закриває скаргу.
  • Загроза життю — радьте телефонувати 102 або 112.
    • {% endif %}

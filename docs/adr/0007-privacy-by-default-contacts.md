# Контакти приховані за замовчуванням, спілкування через чат

Після прийняття волонтера сторони спілкуються у вбудованій розмові; номером телефону кожна сторона ділиться вручну кнопкою. Посилання в чаті показуються як текст, а не як клікабельні — захист вразливих користувачів від фішингу. Виняток: контакт підопічного в запиті «від імені іншої людини» відкривається прийнятому волонтеру автоматично. Модератор бачить розмову лише за наявності скарги.

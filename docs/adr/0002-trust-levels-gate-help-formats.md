# Рівні довіри L0–L2 і доступ за форматом допомоги

Обидві ролі мають три рівні: L0 зареєстрований (лише перегляд), L1 email підтверджено, L2 перевірений. Волонтер L1 може відгукуватись лише на запити без візиту додому; візит додому — тільки L2. Отримувач L1 може створювати запити, але перші три проходять премодерацію; L2 публікує одразу. Так новий користувач отримує користь одразу, а найризиковіший сценарій — чужа людина вдома у вразливої людини — закритий перевіркою.

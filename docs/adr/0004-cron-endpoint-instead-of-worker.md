# Періодичні задачі через HTTP-endpoint, реальний час через polling

Безкоштовний хостинг не дає фонових воркерів і cron. Тому періодичні задачі (прострочення, нагадування, автопідтвердження, скидання демо) — ідемпотентні функції, які викликає захищений токеном `POST /tasks/run/`; його смикає cron-job.org кожні ~10 хвилин, що заодно не дає сервісу заснути. Без Celery/Redis. Сповіщення та чат оновлюються polling-ом: sync-воркери gunicorn на безкоштовному тарифі не тримають довгі SSE/WebSocket-з'єднання.
